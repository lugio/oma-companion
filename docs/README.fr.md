# Alison — en français

← [README (English)](../README.md)

Alison est une compagne de bureau pour **Omarchy 4**. Elle vit dans le shell, répond à l'écrit ou à la
voix, et demande avant de toucher à quoi que ce soit : chaque changement passe par une **carte** que vous
validez d'un clic.

## Installation

```bash
omarchy plugin add https://github.com/lugio/oma-companion --enable
```

Ouvrez le panneau depuis la barre : un **assistant en sept étapes** règle la langue (français ou anglais),
le cerveau, le mode de départ, le nom, la voix, les connexions et le raccourci. Tout se change ensuite
dans les Réglages.

## L'essentiel

- **Cinq modes** de droits, de *Discussion* (aucun outil) à *Autonome* (journalisé, choisi au clic seulement).
- **Voix locale** (parole, mot d'éveil « Salut Alison », transcription), installée uniquement au clic depuis
  les Réglages.
- **Micro sans écho** facultatif, avec l'exemple PipeWire fourni ([voix](voice.md)) ; pour l'annuler,
  retirez le fichier copié puis redémarrez PipeWire.
- **Connexions** facultatives (Home Assistant, courrier, comptabilité) avec vos propres identifiants.
- **Robot** Reachy Mini facultatif.

La documentation détaillée est en anglais : [docs](README.md).
